## 🔧 REGRAS TÉCNICAS OBRIGATÓRIAS

1. Python 3.12+, type hints estritos, docstrings Google style, `__all__` explícito
2. **Pydantic v2** com `model_config = ConfigDict(strict=True, frozen=False)` + `field_validator`
3. **Schemas importados de `/contracts/data_models.py`** — nunca redefina modelos localmente
4. Pandas: `dtype` explícito, `copy=False` quando seguro, `engine='pyarrow'` para CSVs grandes
5. Fail-fast + Early Return em **TODAS** as funções públicas
6. `structlog` JSON em todos os módulos — **NUNCA** `print()` ou `logging.basicConfig()`
7. Separação clara: `src/io/` (ingestão), `src/models/` (schemas locais), `src/analytics/` (regras)

---

## 🛡️ SEGURANÇA & ANTI-INJEÇÃO (CRÍTICO)

1. **Path Traversal**: Use `pathlib.Path.resolve()` + whitelist de extensões (`.csv`, `.xlsx`)
2. **CSV Injection**: Sanitize células que começam com `=`, `+`, `-`, `@` antes de processar
3. **SQL Injection**: TODAS as queries usarão placeholders (`?` ou `$1`) — **NUNCA** f-strings
4. **PII Leakage**: Logs **NUNCA** contêm nomes/CPF crus; use `GradeRecord.hash_student_id()`
5. **Input Validation**: Valide schema Pydantic **ANTES** de qualquer processamento ou chamada de IA
6. **Memory Safety**: Libere DataFrames grandes com `del df; gc.collect()` após uso

## 📊 SCHEMA DE OUTPUT ESPERADO (contrato de entrega)
Todo parser deve retornar uma lista de `GradeRecord` (de `/contracts/data_models.py`):
```python
# Exemplo de output válido
[
    GradeRecord(
        student_hash="a3f1b2c4d5e6",  # SHA-256[:12]
        class_id="9A",
        subject=SubjectEnum.MATEMATICA,
        grade=72.5,
        period="2024-T1",
    ),
    ...
]
```
Qualquer saída deve ser validável com `GradeRecord.model_validate(data)` sem erros.
