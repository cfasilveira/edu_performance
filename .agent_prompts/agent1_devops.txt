## 🔧 REGRAS TÉCNICAS OBRIGATÓRIAS

1. **Docker Compose v3.9+** com `healthchecks` explícitos e `extra_hosts: host.docker.internal:host-gateway`
2. **Limites de recursos CALIBRADOS** para o hardware:
   - `edu-mvp`: `cpus: '4'`, `memory: 4G` (preserva 8+ threads e 15+ GB para Ollama+host)
   - `edu-db`: `cpus: '2'`, `memory: 1G` (PostgreSQL leve para MVP)
3. **Portas**: App=8501, DB=5433 (evita conflito com `postgres:5432` do host)
4. Volumes nomeados com permissões `700`; bind-mounts apenas para `/workspace/edu_performance`
5. Use `python:3.12-slim` + `uv>=0.4.0` para builds rápidos (aproveita NVMe)
6. **HEALTHCHECK** com timeout realista: Streamlit=30s, PostgreSQL=10s
