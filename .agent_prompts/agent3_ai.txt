## 🔧 REGRAS TÉCNICAS OBRIGATÓRIAS

1. **`litellm`** como camada única de abstração (compativel com qualquer modelo Ollama)
2. **`tenacity`** com retry exponencial: máx 2 tentativas, backoff 2–10s, `timeout=60s`
3. Forçar output JSON via system prompt + parsing com `json.loads` + validação Pydantic
4. **Cache** de respostas idênticas com `diskcache` (evita re-inferência; TTL=3600s)
5. Separação clara: `src/llm/client.py` (comunicação), `src/llm/advisor.py` (lógica pedagógica)
6. **Modelo configurável**: leia o modelo ativo de `pedagogical_rules.json["models"]["default"]`;
   use `SupportedModel` de `/contracts/data_models.py` para validar antes de chamar o Ollama:
   ```python
   from contracts.data_models import SupportedModel
   import json
   rules = json.load(open("contracts/pedagogical_rules.json"))
   model = SupportedModel(rules["models"]["default"])  # valida o enum
   ```
7. **Rate limiting**: máx 3 chamadas/minuto ao Ollama — implemente via `asyncio.Semaphore`:
   ```python
   import asyncio
   _LLM_SEMAPHORE = asyncio.Semaphore(1)   # 1 chamada simultânea
   _CALL_INTERVAL = 20.0                    # segundos entre chamadas (60s/3rpm)

   async def call_llm_safe(prompt: str) -> dict:
       async with _LLM_SEMAPHORE:
           result = await _call_ollama(prompt)
           await asyncio.sleep(_CALL_INTERVAL)
           return result
   ```

## 🛡️ SEGURANÇA PEDAGÓGICA & ANTI-PROMPT-INJECTION (CRÍTICO)

1. **System Prompt Imutável**: Defina em constante `SYSTEM_PROMPT: Final[str]` — **NUNCA** concatene com input do usuário
2. **Input Sanitization**: sanitize antes de enviar ao LLM (regex — ver Guardrails)
3. **Output Guardrail**: Valide schema `AIRecommendation` (de `/contracts/data_models.py`) **ANTES** de usar a resposta; fallback imediato se inválido
4. **PII Protection**: Use `GradeRecord.hash_student_id()` — **NUNCA** envie nomes/CPF/endereços ao LLM
5. **Guardrails Pedagógicos**: Tom formativo, "IA sugere, humano decide", mitigue viés, rejeite prompts punitivos/médicos
6. **Rate Limiting Local**: Máx 3 chamadas/minuto (ver impl. acima) para evitar sobrecarga da CPU do host

## 📊 SCHEMA DE OUTPUT ESPERADO (contrato de entrega)
O advisor deve sempre retornar um objeto `AIRecommendation` válido de `/contracts/data_models.py`:
```json
{
  "group_id": "grp_a3f1b2",
  "recommendations": [
    "Formar grupo de reforço em Matemática às quartas-feiras",
    "Utilizar material visual para geometria"
  ],
  "subjects_addressed": ["Matemática"],
  "disclaimer": "IA auxilia, humano decide. Valide com seu julgamento pedagógico antes de agir.",
  "model_used": "mistral"
}
```
Em caso de falha/timeout: retorne `AIRecommendation` com `recommendations=["Análise indisponível. Consulte o professor responsável."]`.

> **Para trocar de modelo**: altere `pedagogical_rules.json["models"]["default"]` e adicione o modelo
> ao `SupportedModel` enum se ainda não estiver. Não é necessário alterar código do advisor.
