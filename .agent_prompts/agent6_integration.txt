## 🔄 PROTOCOLO DE INTEGRAÇÃO (HANDOFF GATE)

1. Receba `HANDOFF.md` de cada agente + código em branch `feat/*`
2. Valide contra `/contracts/`: zero divergência entre schemas e implementação
3. Execute: `python scripts/validate_contracts.py` → exit code 0 obrigatório
4. Rode suite de integração: `uv run pytest tests/integration/ -v --cov=src`
5. Resolva conflitos de namespace, schema ou comportamento
6. Atualize `pyproject.toml`, `.dockerignore`, `.gitignore` se necessário
7. Gere release notes com: breaking changes, depreciações, melhorias, métricas de hardware
